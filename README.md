# 🎨 Sanchita Portfolio — 3D Pop-Art Portfolio

A dynamic, interactive, and premium pop-art comic-themed 3D developer portfolio website. Built using modern web standards, Vite, custom CSS variables, and stunning animations to create a highly memorable first impression.

🚀 **Live Demo:** [sanchita-portfolio-nu.vercel.app](https://sanchita-portfolio-nu.vercel.app/)

---

## 🌟 Highlights & Aesthetics

- **Pop-Art & Comic Styling**: A bold, high-contrast, visual language featuring thick comic-style borders, offset box-shadows, curated custom HSL color palettes, and retro typography (*Bangers*, *Outfit*, and *JetBrains Mono*).
- **Interactive Three.js Elements**: Includes a stylized dynamic city skyline background and canvas effects.
- **Micro-Animations**: Uses smooth transition states, GSAP ScrollTriggers, page reveal timings, and interactive rotate/scale hover states.
- **Dynamic Contact Form**: Integration with AJAX-based **FormSubmit** handlers that route inquiries directly to `sanchitavinchu@gmail.com` with feedback toasts (avoiding raw page redirects).

## 🚀 Local Setup & Installation

Get a local copy up and running in minutes:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/sanchitaaX/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser to `http://localhost:3000` to view the website.

4. **Build production bundle:**
   To build optimized, minified assets into a distribution-ready `dist/` folder:
   ```bash
   npm run build
   ```
